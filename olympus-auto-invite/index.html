Olympus Auto Invite

Pick a keyword. Anyone who whispers it to you gets a guild invite. A tiny addon for World of Warcraft: Classic Forever.

No more retyping a name with three accents in it.

Download for Classic Foreverv1.1.0 · 3 KB · free

An early release. It has been tested against a stand-in for the game’s API, not yet in a live guild.

Set it up

  1. Open Options > AddOns > Olympus Auto Invite, or type /ginv options.
  2. Type a whisper keyword, like inv.
  3. Tick Send a guild invite to anyone who whispers the keyword.

Commands

/ginvguild-invite the last person who whispered you /ginv Nameguild-invite that character instead /ginv on /ginv offturn auto invite on or off /ginv ?show whether auto invite is on, and who /ginv would invite /ginv optionsopen the settings

Install

  1. Exit World of Warcraft.
  2. Unzip the download. You get a folder called OlympusAutoInvite.
  3. Move that folder into the game’s AddOns folder: C:\Program Files (x86)\World of Warcraft\_forever_\Interface\AddOns On a Mac, the folder starts with /Applications/World of Warcraft/. If you installed the game somewhere else, look there.
  4. Check the folder isn’t doubled. This file should exist: ...\AddOns\OlympusAutoInvite\OlympusAutoInvite.toc
  5. Start the game. On the character select screen, click AddOns and make sure Olympus Auto Invite is ticked.

Good to know

  • Auto invite is off until you turn it on, and does nothing while the keyword is blank.
  • The whisper has to be the keyword and nothing else. Capitals don’t matter, so INV matches inv, but inv please doesn’t.
  • The same person can’t set off a second invite for 10 seconds.
  • It tells you in chat who was invited, or why an invite didn’t send: you’re not in a guild, or your rank can’t invite.
  • Battle.net whispers count too, when that friend is on a character in the same version of the game.
  • /ginv on its own remembers whispers from this session only. After a reload or relog, wait for a new whisper or use /ginv Name.
  • Your keyword and the on/off setting are kept between sessions.
