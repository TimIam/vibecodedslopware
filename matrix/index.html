Matrix Rain

The digital rain, on every screen you own. Windows, Mac, Linux: all of them, and all of your monitors at once.

The Windows one is unsigned, so your browser may call it “not commonly downloaded” and Windows may say “Windows protected your PC.” Click Keep, then More info → Run anyway. It’s 14 KB of C# built with the compiler that ships inside Windows; the source is in the matrix/src folder of this site.

Windows

  1. Download MatrixRain.scr and put it somewhere it can stay, like your Documents folder.
  2. Right-click it and choose Install. Screen Saver Settings opens with Matrix Rain selected; pick a wait time and click OK.
  3. It takes over every monitor. Move the mouse or press a key to come back.

Mac

  • Right now: open the web version in Chrome or Edge and click. The browser asks to “manage windows on all your displays”; say yes. Browsers only allow one new window per click, so click once per extra screen, then once on each screen to make it fullscreen. The card tells you what’s next. Safari and Firefox get one screen.
  • As a real screensaver: install WebViewScreenSaver (brew install --cask webviewscreensaver --no-quarantine), choose it in System Settings → Screen Saver, and give it this address: https://vibecodedslopware.com/matrix/rain.html#embed. macOS runs it on every display.

Linux, ChromeOS, anything with a browser

  • Same web version, same clicks: Chrome or Chromium does every monitor, anything else does one.
  • For a hands-off kiosk, chromium --kiosk "https://vibecodedslopware.com/matrix/rain.html#embed" is just rain, no card to click; start and stop it from whatever idle hook you like.

The details

  • Half-width katakana, mirrored like the film, plus digits and a few symbols. Every stream has its own speed, length and depth, and the glyphs shimmer as they fall.
  • The web version is one file with no dependencies. Add #embed to the address for rain with no card.
  • Nothing phones home. Nothing is configurable. It just rains.
